# Sales Analysis Dashboard

Project ini menggunakan Pandas untuk mengolah data transaksi penjualan dan Matplotlib/Seaborn untuk memvisualisasikan hasilnya.

## Fitur
- Load data transaksi dari CSV.
- Menghitung total penjualan (Price * Quantity).
- Agregasi penjualan berdasarkan Kategori.
- Agregasi penjualan harian.
- Menyimpan visualisasi (Bar Chart & Line Chart) sebagai gambar PNG.

## Requirements
- pandas
- matplotlib
- seaborn

## Output
- `category_sales.png`: Grafik total penjualan per kategori.
- `daily_sales.png`: Grafik tren penjualan harian.

## Cara Menjalankan
```bash
python main.py
```
