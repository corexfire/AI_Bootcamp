# Final Project 1: AI Chatbot Assistant
- **Deskripsi**: Membangun Chatbot cerdas yang bisa menjawab pertanyaan pengguna seputar topik tertentu (misal: Layanan Pelanggan Bank atau Info Kesehatan).
- **Fitur Wajib**:
  - Intent Classification (Deep Learning/NLP).
  - Web Interface (Streamlit/Flask).
  - Database untuk menyimpan log percakapan.
- **Tech Stack**: TensorFlow/PyTorch, NLTK, Streamlit, SQLite.

# Final Project 2: Face Attendance System
- **Deskripsi**: Sistem absensi otomatis berbasis pengenalan wajah.
- **Fitur Wajib**:
  - Registrasi wajah pengguna baru.
  - Deteksi dan Pengenalan wajah real-time dari webcam.
  - Mencatat waktu kedatangan ke file CSV/Database.
- **Tech Stack**: OpenCV, Face_recognition lib, Python.

# Final Project 3: Stock Price Prediction
- **Deskripsi**: Dashboard prediksi harga saham menggunakan data historis.
- **Fitur Wajib**:
  - Fetch data saham real-time (Yahoo Finance API).
  - Model Time Series (LSTM/GRU).
  - Visualisasi grafik interaktif.
- **Tech Stack**: TensorFlow (LSTM), Pandas, Streamlit/Dash, Yfinance.
