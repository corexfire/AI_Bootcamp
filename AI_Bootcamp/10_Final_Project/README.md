# Capstone Project Guide

Selamat! Anda telah mencapai tahap akhir dari Bootcamp ini.
Di tahap ini, Anda diminta untuk mengerjakan **1 Proyek Besar** secara mandiri untuk menunjukkan semua skill yang telah dipelajari.

## Checklist Pengerjaan
- [ ] **Perencanaan**: Tentukan topik, scope, dan tech stack. Buat flow chart aplikasi.
- [ ] **Data Gathering**: Kumpulkan dataset (Kaggle, API, atau Scraping).
- [ ] **Data Preprocessing**: Bersihkan dan siapkan data.
- [ ] **Modeling**: Latih model AI (Machine Learning / Deep Learning).
- [ ] **Evaluation**: Pastikan model memiliki akurasi yang layak.
- [ ] **Application**: Buat antarmuka aplikasi (CLI / Web / Desktop).
- [ ] **Documentation**: Tulis README.md yang jelas.

## Kriteria Penilaian
1. **Fungsionalitas**: Aplikasi berjalan tanpa error fatal.
2. **Kualitas Kode**: Kode rapi, modular, dan diberi komentar.
3. **Kompleksitas**: Menggunakan algoritma yang sesuai (bukan sekadar if-else).
4. **Kreativitas**: Solusi unik atau UI yang menarik.

## Submission
Upload kode ke GitHub dan kirimkan link repository kepada instruktur.

Good Luck! 🚀
