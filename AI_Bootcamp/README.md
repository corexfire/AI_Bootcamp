# AI Bootcamp Curriculum Repository

Repository ini berisi materi lengkap, kode, latihan, dan proyek untuk AI Bootcamp (Python to AI Engineer).
Struktur folder disusun berdasarkan Fase pembelajaran selama 16 minggu.

## Struktur Direktori

Setiap fase (01-10) memiliki struktur subfolder standar:
- `code/`: Contoh kode materi pembelajaran.
- `projects/`: Sample project aplikatif dengan instruksi lengkap.
- `data/`: Dataset dummy untuk latihan dan proyek.
- `exercises/`: Soal-soal latihan coding.
- `solutions/`: Jawaban dan pembahasan latihan.

## Daftar Fase

1. **01_Python_Foundation**: Dasar Python, Logika, dan OOP.
2. **02_Math_Statistics**: Matematika (Aljabar Linear, Kalkulus) dan Statistik untuk AI.
3. **03_Data_Analysis**: Data Wrangling dan Visualisasi (Pandas, Matplotlib).
4. **04_Machine_Learning_Basic**: Algoritma ML Dasar (Regression, Classification).
5. **05_Machine_Learning_Advanced**: Optimasi Model, Ensemble Learning.
6. **06_Deep_Learning**: Neural Networks, CNN, RNN (TensorFlow/PyTorch).
7. **07_NLP**: Natural Language Processing (Text Analysis, Chatbot).
8. **08_Computer_Vision**: Image Processing, Object Detection.
9. **09_Deployment**: Model Serving (API, Docker).
10. **10_Final_Project**: Capstone Project dan Portfolio.

## Cara Menggunakan
1. Clone repository ini.
2. Buat virtual environment Python: `python -m venv venv`
3. Install dependencies (jika ada requirements.txt di setiap project).
4. Ikuti materi secara berurutan dari fase 01 hingga 10.

Selamat belajar!
