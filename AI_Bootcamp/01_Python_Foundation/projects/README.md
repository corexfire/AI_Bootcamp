# Student Grade Analysis Project

Project ini adalah implementasi sederhana dari analisis data nilai siswa menggunakan Python dasar dan konsep OOP.

## Fitur
1. Membaca data siswa dari file CSV.
2. Menggunakan Class `Student` untuk merepresentasikan data siswa.
3. Menghitung rata-rata nilai (Matematika, IPA, Bahasa Inggris).
4. Menentukan status kelulusan (Lulus jika rata-rata >= 70).
5. Menampilkan laporan ke terminal dan menyimpannya ke file teks.

## Struktur File
- `main.py`: Script utama program.
- `data/students.csv`: Dataset dummy nilai siswa.

## Cara Menjalankan
1. Pastikan Python 3.x sudah terinstall.
2. Jalankan perintah berikut di terminal:
   ```bash
   python main.py
   ```
3. Hasil analisis akan muncul di layar dan file `report.txt` akan dibuat.

## Konsep yang Digunakan
- File I/O (CSV reading, text writing)
- OOP (Class, Object, Methods)
- List & Dictionary
- Control Flow & Loops
