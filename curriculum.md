# KURIKULUM BOOTCAMP AI PYTHON

## 🎯 Tujuan Bootcamp

Membekali peserta dengan kemampuan **membangun Artificial Intelligence (AI) menggunakan Python** dari nol hingga siap **membuat project nyata dan deploy ke production**.

Target lulusan:

* Junior AI Engineer
* Machine Learning Engineer (Entry-Level)
* AI Developer (Web / Backend / Data)

Durasi bootcamp: **16 Minggu (4 Bulan)**
Metode: **Theory (30%) – Practice & Project (70%)**

---

## 🗂️ STRUKTUR KURIKULUM

### 🔰 FASE 1 – Python & Logical Foundation (Week 1–2)

**Tujuan:** Menguasai Python sebagai fondasi AI

#### Materi:

* Pengenalan AI & Machine Learning
* Python Syntax & Best Practice
* Variable, Data Type, Control Flow
* Function & Modular Programming
* OOP (Class, Object, Inheritance)
* Virtual Environment & Package Manager (pip)

#### Tools:

* Python 3.x
* VS Code
* Git & GitHub

#### Mini Project:

* Data processing sederhana
* Program analisis nilai mahasiswa

---

### 🔢 FASE 2 – Matematika & Statistik untuk AI (Week 3)

**Tujuan:** Memahami logika matematis AI

#### Materi:

* Aljabar Linear (Vector, Matrix)
* Statistik Deskriptif
* Probabilitas Dasar
* Kalkulus Dasar (Gradient)

#### Tools:

* NumPy
* SciPy

#### Mini Project:

* Implementasi perhitungan statistik dengan NumPy

---

### 📊 FASE 3 – Data Analysis & Visualization (Week 4–5)

**Tujuan:** Mengolah dan memahami data

#### Materi:

* Data Wrangling (CSV, Excel, JSON)
* Data Cleaning
* Handling Missing Value
* Exploratory Data Analysis (EDA)
* Data Visualization

#### Tools:

* Pandas
* Matplotlib
* Seaborn

#### Project:

* Analisis dataset penjualan / kesehatan

---

### 🤖 FASE 4 – Machine Learning Dasar (Week 6–7)

**Tujuan:** Membuat model AI pertama

#### Tools:

* Scikit-learn

#### Project:

---
